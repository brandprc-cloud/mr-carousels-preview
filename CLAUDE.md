# mr-carousels-preview

## Доска задач — обязательный протокол

Доска — [docs/task-board.html](docs/task-board.html): задачи лежат в массиве `TASKS`
внутри файла (статусы `planned` / `in_progress` / `done` / `cancelled` / `backlog`),
колонки рендерятся скриптом, страница сама обновляется каждые 15 секунд.
Полная документация — в комментарии в начале файла доски. Правила:

1. **Перед началом любой задачи** по коду или спецификациям — проверить доску.
   Если задачи нет — завести (следующий свободный `T-номер`, этап, статус `planned`).
2. **При старте работы** — перевести в `in_progress`, заполнить `started`
   (ГГГГ-ММ-ДД), `session` (краткая метка сессии) и `moved_at`.
3. **При завершении** — `done` + `finished` + `moved_at`; при отмене —
   `cancelled` + причина в `note` + обновлённый `moved_at`.
4. **Зависшие задачи**: если в «Выполняется» висит задача другой сессии — работу
   не начинать, сообщить пользователю и ждать подтверждения. Доска подсвечивает
   красным задачи, находящиеся в работе дольше 2 часов.
5. **`moved_at` — при каждой смене статуса**: точное время ISO с таймзоной,
   команда `date '+%Y-%m-%dT%H:%M:%S%z'`.
6. После любого изменения доски — обновить `LAST_UPDATED` (дата и время).
7. **Жёлтый баннер самопроверки** на доске = нарушение протокола в данных
   (дубль номера, битый статус или незаполненные поля) — устранить правкой
   `TASKS` до начала другой работы.
8. **Идеи и отложенное** — статус `backlog`: колонка скрыта за кнопкой в шапке
   и в прогресс проекта не входит. Заметил задачу, которую стоит сделать
   когда-нибудь, — заведи её туда, не теряй.
9. **Пользователь двигает карточки сам** — мышью на доске, с записью прямо
   в файл (метка сессии «вручную с доски»). Такой статус или этап — его решение:
   не откатывать, при расхождении с планом спросить.

**Как открыть доску.** Файл лежит на сервере, браузер — на машине владельца.
Постоянный сервер досок: `http://127.0.0.1:8779/` — список всех досок,
`http://127.0.0.1:8779/mr-carousels-preview/task-board.html` — эта. Поднимать руками ничего
не нужно, процесс держится кроном (`~/projects/server-scripts/board-server.sh`).
Кнопка «Записать в файл» работает через этот же сервер.

**Связь с дашбордом `founder-platform`.** Этого проекта в дашборде нет —
доска здесь единственный список задач. Появится проект в дашборде — решать,
что главнее, надо будет явно, а не заводить два списка молча.
